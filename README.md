# Screenia

Browser-based screen, webcam and audio recorder.

## Features

- Screen, webcam and audio recording
- Login and pricing

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/screenia-capture-editor.git
cd screenia-capture-editor
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
